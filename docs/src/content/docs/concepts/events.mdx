## EventBus

The `EventBus` is a global publish/subscribe system. Every `bus.on()` call
returns an unsubscribe function — call it to stop listening:

```typescript
import { EventBus } from "@yagejs/core";

const bus = new EventBus<{
  "player:hit": { damage: number };
  "level:complete": { levelId: string };
}>();

// Subscribe — returns an unsubscribe function
const off = bus.on("player:hit", (data) => {
  console.log("Ouch!", data.damage);
});

// Subscribe for a single occurrence
bus.once("level:complete", (data) => {
  console.log("Level cleared:", data.levelId);
});

// Emit an event
bus.emit("player:hit", { damage: 25 });

// Unsubscribe when done
off();
```

## Built-in Engine Events

The engine emits these events automatically through the global `EventBus`:

| Event | Payload | When |
|---|---|---|
| `entity:created` | `{ entity }` | An entity is spawned |
| `entity:destroyed` | `{ entity }` | An entity is destroyed, on the end-of-frame flush or on scene teardown |
| `component:added` | `{ entity, component }` | A component is added to an entity |
| `component:removed` | `{ entity, componentClass }` | A component is removed from an entity |
| `scene:pushed` | `{ scene }` | A scene is pushed onto the stack |
| `scene:popped` | `{ scene }` | A scene is popped from the stack |
| `scene:replaced` | `{ oldScene, newScene }` | The top scene is replaced |
| `scene:transition:started` | `{ kind, fromScene, toScene }` | A scene transition begins |
| `scene:transition:ended` | `{ kind, fromScene, toScene }` | A scene transition finishes |
| `scene:loading:progress` | `{ scene, ratio }` | A loading scene reports progress (0 to 1) |
| `scene:loading:done` | `{ scene }` | A loading scene has finished loading |
| `engine:started` | `undefined` | The engine loop has started |
| `engine:stopped` | `undefined` | The engine is being destroyed |
| `screen:fullscreen` | `{ active }` | The canvas host entered or left fullscreen |
| `screen:orientation` | `{ type }` | The device orientation changed |

`entity` in the `entity:*` and `component:*` payloads is the live `Entity`,
so a listener can read its tags and components. The `scene` fields carry
`{ name }`, except the loading events, which carry the `Scene`.

From a component, subscribe with `this.listenBus(event, handler)`. The
subscription is released when the component is removed or its entity is
destroyed:

```typescript
import { Component } from "@yagejs/core";

class ScoreTracker extends Component {
  score = 0;

  onAdd() {
    this.listenBus("entity:destroyed", ({ entity }) => {
      if (entity.tags.has("enemy")) {
        this.score += 100;
      }
    });
  }
}
```

Outside a component, resolve the bus with `context.resolve(EventBusKey)` and
keep the unsubscribe function `bus.on` returns.

## Typed EventBus

For custom events with full type safety, create a typed bus with an interface:

```typescript
import { EventBus } from "@yagejs/core";

interface GameEvents {
  "player:hit": { damage: number; source: string };
  "item:collected": { itemId: string; value: number };
  "wave:started": { waveNumber: number };
}

const bus = new EventBus<GameEvents>();

// Fully typed — data shape is inferred
bus.on("player:hit", (data) => {
  //                   ^? { damage: number; source: string }
  console.log(data.damage);
});

// Type error if payload doesn't match
bus.emit("item:collected", { itemId: "gem", value: 50 });
```

## EventToken and defineEvent

Entity and scene events are addressed by an `EventToken`, not by a string.
`defineEvent` creates one and pairs the event name with its payload type, so
every `on` and `emit` site is checked against the same shape:

```typescript yage-context="scene"
import { defineEvent } from "@yagejs/core";

// Define once in a shared module
export const PlayerHitEvent = defineEvent<{ damage: number }>("player:hit");
export const WaveStartEvent = defineEvent<{ waveNumber: number }>(
  "wave:started",
);

// Tokens address entity.on / entity.emit and scene.on / scene.emit
const player = scene.spawn("player");
player.on(PlayerHitEvent, (data) => {
  console.log(data.damage);
});
player.emit(PlayerHitEvent, { damage: 30 });

scene.emit(WaveStartEvent, { waveNumber: 2 });
```

The `EventBus` is keyed by string and does not take tokens:
`bus.on(PlayerHitEvent, ...)` does not compile.

Dispatch is by the token's name, not by the token object. Two `defineEvent`
calls with the same name are one channel, and their payload types are not
checked against each other. Prefix names with the owning module
(`"inventory:item-added"`) to keep them distinct. In dev builds the second
definition of a name logs a warning; an empty name throws.

## Entity-Scoped Events

Entities have their own lightweight event emitter for local communication
between components on the same entity:

```typescript
import { Component, defineEvent } from "@yagejs/core";
import { SpriteComponent } from "@yagejs/renderer";
import { hitFlash } from "@yagejs/effects";

const DamagedEvent = defineEvent<{ amount: number }>("damaged");

class Health extends Component {
  current = 100;

  takeDamage(amount: number) {
    this.current -= amount;
    this.entity.emit(DamagedEvent, { amount });
  }
}

class DamageFlash extends Component {
  onAdd() {
    this.listen(this.entity, DamagedEvent, ({ amount }) => {
      this.sibling(SpriteComponent)
        .fx.addEffect(hitFlash({ color: amount > 50 ? 0xff0000 : 0xffffff }))
        .trigger();
    });
  }
}
```

A subscription made with `this.listen` is released when the component is
removed or its entity is destroyed. `this.listen` takes any entity, so a
component can follow another entity's events, and that subscription is still
released with the component. A bare `entity.on` subscription is released only
when that entity is destroyed.

## Scene-Level Event Subscription

A scene can subscribe to an `EventToken` and pick up **both** events it
emits itself and events emitted by any of its entities. The handler
takes an optional second argument — the source `Entity` for bubbled
events, or `undefined` for scene-emitted ones — so a single handler can
distinguish the two cases:

```typescript
import { Scene, defineEvent, type Entity } from "@yagejs/core";

const DamagedEvent = defineEvent<{ amount: number }>("damaged");

class GameScene extends Scene {
  readonly name = "game";

  onEnter() {
    this.on(DamagedEvent, (data, entity?: Entity) => {
      if (entity) {
        // Bubbled — the source called `entity.emit(DamagedEvent, ...)`
        console.log(`${entity.name} took ${data.amount} damage`);
      } else {
        // Scene-emitted via `scene.emit(DamagedEvent, ...)`
        console.log(`scene-wide damage broadcast: ${data.amount}`);
      }
    });

    // Triggers the `entity = undefined` branch above
    this.emit(DamagedEvent, { amount: 5 });

    // Triggers the bubbled branch with `entity = enemy`
    const enemy = this.spawn("enemy");
    enemy.emit(DamagedEvent, { amount: 10 });
  }
}
```

`Scene.on` returns an unsubscribe function. The handler signature is
`(data, entity?)` for every subscription — check `entity` to decide
whether you can read source state (`entity.get(Health)`, etc.) or
you're handling a scene-wide broadcast.

Scene-level subscriptions are released when the scene exits, together with
its entities. Subscribe in `onEnter`, as above, or from a component with
`this.listenScene(token, handler)`, which is released with the component. A
scene instance that is pushed again starts with no subscriptions.

This is the canonical way to react to per-entity events at the scene
level — for example, when a `Health` component on any entity emits
`DamagedEvent`, a scene-level subscriber can roll those into a global
damage feed, trigger a screen-shake, or update an aggregate UI store
without each entity having to know who's listening.
