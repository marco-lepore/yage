title: Character Controller
description: Platformer movement with ready-to-use defaults and replaceable input, moves, and movement policies.
---

The character-controller addon gives a physics body responsive platformer
movement: running, buffered jumps, short hops, air jumps, dashes, wall jumps,
crouching, slides, and dropping through one-way platforms. Terrain assistance
handles slopes and small steps. Moving platforms carry the character,
including into a jump.

Try the [movement playground](https://examples.yage.dev/character-controller.html).
Each zone shows one feature: jumps and one-way platforms, slides, steps,
slopes, a moving platform, a ledge climb, and wall jumps. Use **[** and **]**
to visit a zone and **R** to restart there. Press **1** or **2** to compare
default and nimble tuning, **F** to block or allow dashes, and **C** to refill
air charges. The ledge climb is a move the example builds on `LedgeProbe`:
fall past a ledge while holding toward it, then press jump to climb.

## Install and create a player

```sh
npm install @yagejs-addons/character-controller @yagejs/core @yagejs/physics @yagejs/input
```

Install physics and input before entering your scene:

```ts yage-context=engine
import { PhysicsPlugin } from "@yagejs/physics";
import { InputPlugin } from "@yagejs/input";
import { platformerControls } from "@yagejs-addons/character-controller";

engine.use(new PhysicsPlugin());
engine.use(new InputPlugin({ actions: platformerControls() }));
```

Add a Transform and create the controller in your entity's setup. The helper
creates the body, collider, probes, input, and standard moves.

```ts
import { Entity, Transform } from "@yagejs/core";
import { createPlatformer } from "@yagejs-addons/character-controller";

class Player extends Entity {
  setup(): void {
    this.add(new Transform());
    createPlatformer(this);
  }
}
```

Spawn `Player` in a `Scene` with solid physics colliders. The character's
origin is at its feet. Keep its Transform upright with world scale 1, and
draw it with a sprite or graphics on the same entity or on a child. Flip or
scale a visual child rather than the character's Transform.

The default body is a box 16 pixels wide and 44 pixels tall. It has fixed
rotation, continuous collision detection, zero friction, and gravity applied
by the controller. The addon does not need a rendering package.

## Adjust movement

Override only the numbers your game needs. The defaults suit a world with
16-pixel tiles. All distances use pixels and all durations use seconds.

```ts
import { Entity, Transform } from "@yagejs/core";
import { createPlatformer } from "@yagejs-addons/character-controller";

class Player extends Entity {
  setup(): void {
    this.add(new Transform());
    createPlatformer(this, {
      tuning: { runSpeed: 220, jumpSpeed: 460, airJumps: 0 },
      dash: false,
    });
  }
}
```

Tuning is copied when the character is created. An invalid number throws
before the helper adds any component.

| Behavior | Default |
| --- | --- |
| Run speed | 190 px/s |
| Ground / air acceleration | 1700 / 1500 px/s² |
| Jump / air-jump speed | 434 / 360 px/s |
| Air jumps / air dashes | 1 / 1 |
| Coyote time / press buffer | 0.1 / 0.12 seconds |
| Short-hop release window | 0.2 seconds |
| Dash speed / duration / cooldown | 520 px/s / 0.27 / 0.6 seconds |
| Slide speed / crouched height | 450 px/s / 30 pixels |
| Drop-through time | 0.25 seconds |
| Maximum slope / small step | 45 degrees / 6 pixels |

`defaultPlatformerTuning()` returns every default as a plain object. The
[complete tuning reference](/llms/addons/character-controller.md) lists each
field. Set `dash`, `wallJump`, `slide`, or `dropThrough` to false to turn off
that standard move.

A ground jump stays available briefly after walking off a ledge. A press just
before landing waits for contact. Releasing jump early makes a short hop.
Holding jump through the release window keeps the rest of the rise. A wall
jump needs the player to hold toward the wall. A slide starts when the player
crouches while running. Crouching under a low ceiling keeps the body low until
there is room to stand.

Two settings on the controller change while the game runs. `speedScale`
multiplies the run speed, for water, mud, or a heavy item. `wallClingEnabled`
turns the slow slide down a held wall on and off.

```ts
import { Component } from "@yagejs/core";
import { PlatformerController } from "@yagejs-addons/character-controller";

/** Halves the run speed while this component is on the character. */
class Swimming extends Component {
  private readonly controller = this.sibling(PlatformerController);

  onEnable(): void {
    this.controller.speedScale = 0.5;
  }

  onDisable(): void {
    this.controller.speedScale = 1;
  }
}
```

## Control move eligibility and restore charges

Use `admissionPolicies.canStartMove` for stamina, move unlocks, or temporary
restrictions. The policy receives the move name and a snapshot of contact,
stance, and remaining air charges. Return false to block the move.

```ts
import { Entity, Transform } from "@yagejs/core";
import {
  createPlatformer,
  PlatformerDashedEvent,
} from "@yagejs-addons/character-controller";

class Player extends Entity {
  stamina = 20;

  setup(): void {
    this.add(new Transform());
    createPlatformer(this, {
      admissionPolicies: {
        canStartMove: (move) => move !== "dash" || this.stamina >= 10,
      },
    });
    this.on(PlatformerDashedEvent, () => {
      this.stamina -= 10;
    });
  }
}
```

Move names are `groundJump`, `airJump`, `wallJump`, `dash`, `slide`, and
`dropThrough`. The policy adds game requirements on top of the controller's
own checks for contact, headroom, charges, and cooldown. Readiness queries
such as `moves.dashReady` also call it, so it can run more than once per step.
Keep it free of side effects and apply consequences in move events. A denied
press stays buffered until its usual expiry. Air jumps need the character to
be airborne, so denying a ground jump never spends an air jump while standing.

Read `character.admission.airCharges` for `{ jumps, dashes }`. Set either
count with `setAirCharges`, or call `refillAirCharges()` to restore both
tuning defaults. A pickup can restore one air dash:

```ts
import { Component } from "@yagejs/core";
import { MoveAdmission } from "@yagejs-addons/character-controller";

/** On the player. A refill crystal calls `collectCrystal` when touched. */
class Pickups extends Component {
  private readonly admission = this.sibling(MoveAdmission);

  collectCrystal(): void {
    this.admission.setAirCharges({ dashes: 1 });
  }
}
```

Counts must be nonnegative safe integers and may exceed the tuning defaults.
These methods do not reset the dash cooldown or start a move.

Landing restores the tuning defaults. Override
`admissionPolicies.landingCharges` to choose the counts after ground contact:

```ts
import { Entity, Transform } from "@yagejs/core";
import { createPlatformer } from "@yagejs-addons/character-controller";

class Player extends Entity {
  setup(): void {
    this.add(new Transform());
    const character = createPlatformer(this, {
      admissionPolicies: {
        landingCharges: ({ airCharges }) => airCharges,
      },
    });
    character.admission.setAirCharges({ jumps: 2, dashes: 1 });
  }
}
```

This policy keeps the remaining charges on landing, so the game restores them
only through pickups or other effects. It runs once per landing, including
the first ground contact after spawning. A new character has zero air charges
until it touches the ground or the game sets them. `refillAirCharges()` always
uses the tuning defaults and ignores this policy.

Both callbacks receive a detached `MoveAdmissionState` with `grounded`,
`onOneWay`, `crouched`, `blocked`, the remembered `wallSide`, and
`airCharges`. An invalid result throws before admission changes any charge.
A callback that throws is reported through the engine's error boundary.

## Choose input

The default action map uses A/D or the arrows to move, S/down to crouch,
Space/W/up to jump, and Shift to dash. Down plus jump on a one-way platform
drops through it. Gamepads use the left stick or D-pad, A to jump, and B to
dash.

With a renderer, mouse and touch also work through screen zones: hold the
left quarter to move left, the next quarter to move right, and the right half
to jump. Each press keeps its role until release or an input reset. Presses
that a UI element consumed are ignored. The zones draw nothing. Use
[Virtual Controls](/addons/virtual-controls/) for a visible stick and buttons,
and pass `input: new PlatformerInputBinding()` to turn the built-in zones off.
The virtual controls then drive the same action names.

Pass `input: null` for AI or scripted movement. No InputPlugin is needed:

```ts
import { Entity, Transform } from "@yagejs/core";
import { createPlatformer } from "@yagejs-addons/character-controller";

class Runner extends Entity {
  setup(): void {
    this.add(new Transform());
    const character = createPlatformer(this, { input: null });
    character.input.setDirection(1);
    character.input.setJumpHeld(true);
    character.input.jump();
  }
}
```

Release jump with `setJumpHeld(false)`. Use `setDown(true)` to crouch,
`dash()` to request a dash, and `drop()` to drop through a one-way platform.
A custom `InputBinding` replaces the default devices. Its `bind`, `poll`, and
`dispose` methods call the same control methods. A binding is disposed when
the character is disabled and bound again when it is enabled. Disabling
`character.input` alone, for a cutscene, disposes the binding, discards
buffered presses, and releases jump, so a held jump becomes a short hop. A
dash or wall jump already under way finishes.

With a device binding, `InputManager.clearAll()` clears the held direction and
the buffered jump, dash, and drop presses, including presses buffered while
time is frozen. An active dash and its cooldown continue. For scripted input,
call `character.moves.resetInput()` to discard buffered presses and release
jump without interrupting active moves.

## One-way platforms and collision layers

A collider with `oneWay: {}` is a one-way platform: the character jumps up
through it and lands on top. Down plus jump on one drops through it for
`dropThroughTime` seconds, and the character emits `PlatformerDroppedEvent`.
Bind a separate drop button by calling `character.moves.drop()`. A drop
spends the ground jump until the next landing, and it works under a low
ceiling where a jump would be blocked. Block it with the `dropThrough` move
name in `canStartMove`, or turn it off with `dropThrough: false`. With drops
off, down plus jump is an ordinary jump.

The character's probes measure the world as the character's own collider. A
surface counts as ground, wall, or ceiling only if the character would
collide with it. Collision layers, sensors, and contact filters all apply, so
the underside of a one-way platform is not a ceiling and its side is not a
wall. Passing through a platform is not a landing and does not restore air
charges.

Set the layers of the created collider with `layers` and `mask`:

```ts
import { Entity, Transform } from "@yagejs/core";
import { CollisionLayers } from "@yagejs/physics";
import { createPlatformer } from "@yagejs-addons/character-controller";

const layers = new CollisionLayers();
const PLAYER = layers.define("player");
const TERRAIN = layers.define("terrain");

class Player extends Entity {
  setup(): void {
    this.add(new Transform());
    createPlatformer(this, { layers: PLAYER, mask: TERRAIN });
  }
}
```

`character.controller.onOneWay` reports whether the character stands on a
collider configured as one-way. Terrain assistance can leave a small gap
above a surface, so use `controller.grounded` and `PlatformerLandedEvent` for
ground contact in game logic.

## Add animation and game effects

Read `character.controller.grounded`, `facing`, `clinging`, and `blocked`,
`character.stance.crouched`, and `character.moves.dashing` for animation.
`character.motion.ownVelocityX` is the running speed relative to a moving
platform. `velocityX` and `velocityY` are the movement through the world.

Listen on the character entity for `PlatformerJumpedEvent`,
`PlatformerDashedEvent`, `PlatformerSlidEvent`, `PlatformerDroppedEvent`, and
`PlatformerLandedEvent`. Jump events report `kind`: ground, air, or wall. Dash
events report the direction. The game decides which sounds, particles, or
combat effects follow.

## Add your own movement

`createPlatformer` returns each component, so game logic can read the probes
and submit motion without going through input. Every movement producer
submits requests to one `MotionReconciler`. Each step, the reconciler picks
the highest-priority request on each axis and writes the body's velocity
once. Running and gravity submit at priority 0 and the standard moves at 10.

A glide holds the fall speed down with a request above running and gravity:

```ts
import { Component } from "@yagejs/core";
import { InputManagerKey } from "@yagejs/input";
import { MotionReconciler } from "@yagejs-addons/character-controller";

/** Slows the fall to 60 px/s while the glide action is held. */
class Glide extends Component {
  private readonly input = this.service(InputManagerKey);
  private readonly motion = this.sibling(MotionReconciler);

  fixedUpdate(): void {
    if (!this.input.isPressed("glide") || this.motion.velocityY < 0) return;
    this.motion.submit({
      source: "glide",
      axis: "y",
      target: 60,
      acceleration: 2000,
      priority: 5,
    });
  }
}
```

Add the component to the character entity in any order. The character's
components declare an `updatePriority`, so the probes and controller update
before a component at the default priority, and the reconciler updates after
it. Add `"glide"` to the InputPlugin's actions for this example.

A knockback uses a priority above 10 and cancels the standard moves:

```ts
import { Component } from "@yagejs/core";
import {
  MotionReconciler,
  PlatformerMoves,
} from "@yagejs-addons/character-controller";

class Knockback extends Component {
  private readonly moves = this.sibling(PlatformerMoves);
  private readonly motion = this.sibling(MotionReconciler);

  hit(direction: -1 | 1): void {
    this.moves.cancel();
    this.motion.submitOnce({
      source: "knockback",
      axis: "x",
      target: direction * 300,
      acceleration: Infinity,
      priority: 100,
    });
  }
}
```

`submit` lasts one step. `submitOnce` waits through a freeze and competes on
the next step that advances. `submitDurable` stays until its handle ends or
cancels it. Two winning requests with equal priority throw. A request that
overrides an axis does not cancel another producer's timers, so call
`moves.cancel()` when the game interrupts the standard moves. Pass a
`resolveMotion` function to replace how the reconciler picks between requests.

To use your own body, add a `RigidBodyComponent` and a `ColliderComponent`
before calling `createPlatformer`. The body must be dynamic with
`gravityScale: 0` and `fixedRotation: true`. The collider must be one box
whose bottom edge sits on the entity's origin, so its offset is
`{ x: 0, y: -height / 2 }`. The helper takes the body size from the box and
throws if the body or collider does not match, or if `bodyWidth`,
`bodyHeight`, `layers`, or `mask` is also given. Give the collider
`friction: 0`, as the created collider has. The helper does not check
friction.

## Ledges

Catching, hanging from, and climbing a ledge are moves the game builds, since
their timing and animation differ between games. `LedgeProbe` supplies the
geometry. Add it to the character, then call `find(side)` while the character
falls. It returns the ledge on that side when the top is within reach of the
hands and the climb is clear. `points(contact)` returns the hang, raised, and
standing positions, and `clearStep(from, to, contact, dt)` checks each step of
the climb, including on a moving ledge.

```ts
import { Entity, Transform } from "@yagejs/core";
import {
  createPlatformer,
  LedgeProbe,
} from "@yagejs-addons/character-controller";

class Player extends Entity {
  setup(): void {
    this.add(new Transform());
    createPlatformer(this);
    this.add(
      new LedgeProbe({
        tuning: {
          ledgeHandHeight: 32,
          ledgeGrabReach: 10,
          ledgeGrabTolerance: 12,
        },
      }),
    );
  }
}
```

The game's climb component moves the body between the points with motion
requests above priority 10, and blocks the standard moves with
`canStartMove` while it holds the ledge. A jump press then waits in the
moves' buffer, and `character.moves.consumeJumpPress()` takes it, so the climb
works with keyboard, gamepad, touch, and scripted input alike. The
playground's `LedgeClimb` component in
`examples/src/character-controller/ledge.ts` is a complete catch, hang, and
climb. A jump away from a held ledge calls
`admission.recordLedgeJump()` once. The call counts the jump in `jumpsTaken`
and uses up the ground and wall jump without spending an air charge.

## Moving platforms and crushing

`MovingSurface({ from, to, speed })` moves an upright kinematic platform back
and forth between two world points. Spawn moving platforms before the
characters that ride them, so each platform's velocity for the step is known
when a rider reads it. Upward platform velocity adds to jump height. Downward
platform velocity does not reduce a jump. Changing a platform entity's time
scale changes its path speed and the speed it carries riders at together.
Time scale zero stops the platform, and a rider on it stops too.

Set `crush: true` to receive `PlatformerCrushedEvent` when a moving box pushes
the character into a fixed opposing face. The event names the pushing
surface, the obstruction, and the push direction. The game decides damage or
recovery. A rotating support, an angled wedge, and two moving blockers are not
detected.

Controller timers and pending motion are not saved. Create the character again
when restoring a saved spawn position.
