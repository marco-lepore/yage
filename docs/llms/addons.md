# YAGE Addons

Gameplay addons (dialogue, inventory, quests, and more) ship under the
`@yagejs-addons/*` npm scope, separate from the engine's `@yagejs/*` packages,
and are versioned independently.

Their reference docs are not in this `docs/llms/` tree. Each addon's doc is
co-located with its package at `packages/addons/<name>/docs/llms/<name>.md`, and
the docs site serves them at `llms/addons/<name>.md`.

The current list, with one-line descriptions, is in `llms.txt` under the
"Addons" heading.
