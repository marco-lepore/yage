# @yagejs-addons/hotbar

Bind abilities, consumables and game actions to numbered slots. The headless model owns assignments and selection; action owners supply live availability, cooldowns and activation results. `hotbarAbility()` and `hotbarItem()` bind an `Abilities` component or an `Inventory` directly. An optional controller and default view add keyboard, gamepad, mouse and touch controls, including held actions and a drag-to-swap edit mode.

See the [guide](https://yage.dev/addons/hotbar/), [runnable example](https://examples.yage.dev/hotbar.html), and [API reference](docs/llms/hotbar.md).
