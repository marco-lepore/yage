# @yagejs-addons/hotbar

Bind abilities, consumables and game actions to numbered slots. The headless model owns assignments and selection; action owners supply live availability, cooldowns and activation results. An optional controller and default presenter add keyboard, gamepad, mouse and touch controls.

See the [guide](https://yage.dev/addons/hotbar/), [runnable example](https://examples.yage.dev/hotbar.html), and [API reference](docs/llms/hotbar.md).
