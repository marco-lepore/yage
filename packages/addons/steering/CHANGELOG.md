## 0.1.0

### Minor Changes

- [#174](https://github.com/marco-lepore/yage/pull/174) [`9ee8b30`](https://github.com/marco-lepore/yage/commit/9ee8b303555466963fb0c79d39730efff0858ea6) Thanks [@marco-lepore](https://github.com/marco-lepore)! - Add `@yagejs-addons/steering`, a steering (movement AI) addon: seek, flee, arrive, wander, pursue/evade, obstacle avoidance, flocking, path-following, and containment, blended into a desired velocity. The root entry is pure `@yagejs/core`; `@yagejs-addons/steering/physics` adds a `RigidBodyComponent`-detecting agent behind an optional `@yagejs/physics` peer.
  - **Headless model** (root entry `.`): `Steering` arbitrates behaviors by `priority` tier (highest first; the first tier whose weighted sum is non-zero wins outright and lower tiers are not evaluated that frame) and blends within a tier by `weight` (default 1), clamping the result to `agent.maxSpeed`. Everything on the default priority 0 is a plain weighted sum; `avoidObstacles(rocks, { priority: 1 })` makes avoidance override seek instead of out-voting it. Twelve behavior factories — `seek`, `flee` (with an optional flee-only-if-near `radius`), `arrive` (linear speed ramp inside `slowRadius`, settles inside `arriveRadius`, fires `onArrive`/`onDepart` once per crossing), `wander` (a slowly-turning circle ahead of the current heading, with an injectable `random` for deterministic tests), `pursue`/`evade` (lead a moving target by up to `maxPrediction` seconds, collapsing to plain seek/flee for a stationary one), `avoidObstacles` (look-ahead ray, steers around the closest threat in path), `separation`/`alignment`/`cohesion` (the three boid rules, game-supplied neighbor lists), `followPath` (waypoints in order with a `waypointRadius` advance; `loop` patrols forever, otherwise the final waypoint gets arrive semantics; progress is readable via the returned behavior's `waypointIndex` and restorable via `startAt` — an index or `"nearest"` — and it takes a plain `Vec2Like[]`, so `@yagejs/pathfinding`'s `Path.waypoints` feeds it with no dependency), and `contain` (steers back inside a `{ x, y, width, height }` rect before the look-ahead point crosses an edge). Targets, obstacles, and neighbors all accept either a static value or a `() => value` provider, resolved live each tick.
  - **`SteeringAgent`** (a `@yagejs/core` Component, the L2a host): computes a desired velocity each `update(dt)` and applies it — kinematic Transform integration by default, or a structural `body` (`VelocityBody` `{ setVelocity, getVelocity }` / `ImpulseBody` `{ applyImpulse, getVelocity, getMass }`, both satisfied by `RigidBodyComponent` without an import). With a `body`, behaviors and the `maxAcceleration` ramp read the body's **actual** velocity, so collisions, wall pins, and knockback feed back into steering. `drive: "velocity"` (default) writes the commanded velocity; `drive: "impulse"` applies the capped correction (`clamp(desired − actual, maxAcceleration·dt) × mass`) through `applyImpulse`, so external impulses compose — a dynamic agent pushes and is pushed. `maxAcceleration` defaults to `4 × maxSpeed` — the acceleration cap doubles as the low-pass that keeps steering smooth when the blend flips direction between frames (`Infinity` opts into an instant snap). `stop()` zeroes the model and pushes a zero through the output (`setVelocity(0)`, a counter-impulse, or `apply(ZERO)`). `faceHeading` rotates the Transform to the travel direction (skipping sub-1 px/s jitter). Live escape hatches: `agent.steering`, `agent.velocity`, `agent.maxSpeed`, `agent.stop()`, `enabled`.
  - **`PhysicsSteeringAgent`** (`/physics` entry): resolves the `RigidBodyComponent` sibling itself and defaults to impulse drive — mount next to a body and collider, nothing to wire. Query it back with `entity.get(PhysicsSteeringAgent)` (components are keyed by exact class).
  - **Physics-backed discovery** (`/physics` entry): `avoidColliders(world, { lookAhead, whiskerAngle, whiskerLength })` raycasts the real world along the heading (center ray + two whiskers) and steers away from the closest hit — no obstacle list, tilemap walls and crates count, the agent's own collider is excluded. `physicsNeighbors(world, { radius, filterGroups })` is a `NeighborsSource` over `PhysicsWorld.queryRadius` for flocking against whatever is physically nearby. Target/obstacle/neighbor providers receive the agent's state (`(agent) => value`), which carries the hosting entity for self-exclusion.
  - **No presenters, no game-defined ID type parameter, no entity-event stream** — the discrete consequences (arrival) surface via `onArrive`/`onDepart` callbacks, and a game wires its own event in one line if it wants one.

  Independently versioned (not part of the `@yagejs/*` fixed group), first publish `0.1.0`. Peers: `@yagejs/core` (required), `@yagejs/physics` (optional, `/physics` entry only).
