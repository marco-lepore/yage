Keyboard & Gamepad Focus

Arrows / WASD / d-pad / left stick move, and repeat while held · Enter or A confirms · Esc or B cancels · Tabs: ← → run the strip, Enter relabels the grid · Menu: the rows pass focusStyle: null and show a > marker from onFocusChange; every other element draws the outline set on the plugin. ↑ ↓ step over the disabled row and wrap at the ends · Grid: all four directions move by position, and off an edge focus carries on into the next pane · Steppers: ← → change the value and keep focus. Pointer focus picks what the mouse does to focus: press focuses on click, hover focuses under the pointer, none leaves focus to the keys. The Dialog owns the pointer checkbox picks whether the open dialog blocks clicks on the menu behind it · Widgets: the slider and the radios step on ← →; Enter opens the select or types into the field, which then holds the keys until Enter or Esc · Save Slots: hold ↓ and the list scrolls to follow the focus · Dialog: Enter on Quit Game or a save slot opens it; Esc closes it and focus returns to the row that opened it · F fires a gameplay action, and the status panel counts every Enter gameplay still hears
