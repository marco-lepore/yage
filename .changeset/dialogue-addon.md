Add `@yagejs-addons/dialogue`, the first YAGE addon: a self-contained, themeable dialogue system.

- **Headless core** (root entry `.`): runner/session/types, markup parser, i18n, canonical format, `DialogueController`, events, and pixi-free input bindings over `@yagejs/input`. The root entry never transitively imports `pixi.js` or `@yagejs/renderer`.
- **Game-state via `VariableStorage`**: the bridge between a game and a conversation is installed once on the controller (`storage`, `functions`, `commands`); `play(script)` is content-only, with optional per-call overrides. Variables live in one opaque namespace backed by a Yarn-shaped `VariableStorage` (ships `MemoryVariableStorage` + `cells` two-way accessors + `compose`), persist across plays, and are seeded from a script's `declare` defaults only when absent (a game-linked value always wins). Conditions and `set` values are expression trees (`literal | varRef | call | unary | binary | group`, Yarn-modeled operators) so `gold - 50` and `has_item("key") and not rude` are plain data; `functions` supply argument-capable reads. Commands handle game mutations (`commands` map + optional `fallbackCommand`, still mirrored to `DialogueCommandEvent`); `set` / `ctx.setVar` / `handle.setVar` write through the storage (a read-only cell throws). `defineScript()` infers variable types so `play()` returns a typed `DialogueHandle` (`setVar` / `getVars`); `DialogueController<TStorage>` is generic over its storage. Validated at load-time (references/types) and play-time (storage/functions/commands coverage), throwing `DialogueScriptError` / `DialoguePlayError`. (Replaces the earlier `params` + `onCommand` controller options.)
- **Presenters** (`./presenters` subpath): all pixi-backed rendering — Graphics chrome + canvas `SplitText`/`Text` views, avatars, composites, and factories. Zero bundled assets.
- **Zero-config `defaultTheme()`**: Graphics chrome + canvas font with native bold/italic and per-glyph effects. Bitmap fonts are an opt-in theme path (one `bitmapFont` atlas; bold/italic are synthesised, so there are no variant-atlas theme fields). `theme.textured` (nine-slice frame texture + insets) is declared but not consumed yet — the nine-slice chrome branch ships in a follow-up.
- **Content-sized speech bubbles**: `BubbleChrome` grows to fit its wrapped text (via the renderer's `measureWrappedText`) instead of clipping at a fixed height — for bitmap fonts too, which size through the same width-first wrap-aware path as canvas text.
- **VN controls**: session-level auto-advance (`setAutoAdvance(ms | null)`) and a hold-to-confirm skip (`fullControls(choices, { skipHoldMs })`), on top of the existing hold-to-fast-forward.
- **Grapheme-correct reveal**: every character count (run lengths, `[pause]` offsets, per-glyph styles, `charsPerSec`) is in graphemes via `Intl.Segmenter` — the same segmentation pixi's `SplitText` renders one glyph per — so emoji, ZWJ sequences, and combining marks stay aligned during the typewriter reveal. `splitGraphemes()` is exported from the root entry.
- **Opt-in `@experimental` radial choice presenter** under `./presenters`.

Independently versioned (not part of the `@yagejs/*` fixed group). Ships ESM + CJS with type declarations for both entry points.
